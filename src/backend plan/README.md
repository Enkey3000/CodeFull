# Backend plan and source material

This directory is a documentation archive, not a backend implementation. The supplied Backend Plan, architecture, PRD, SRS, security and threat-model drafts, test materials, and gap analysis are retained under `source-materials/`.

Important preserved files include:

- `CodeFull Backend Plan (1).md`, `CodeFull Architecture Document.md`, and `CodeFull Data Model Specification.md`.
- `CodeFull Product Requirements Document (PRD).md`, `CodeFull Software Requirements Specification (SRS).md`, and `CodeFull Points Economy and Rewards Specification.md`.
- Security, threat model, test plan/cases, UAT, release, incident response, pen test, PoC, playbook, execution guide, and readiness materials.
- `openapi.yaml`, extracted AsyncAPI and engineering/security rule drafts, the RTM workbook, original source archives, and the gap analysis DOCX.

The source documents are drafts, proposals, or for review. In particular, the execution-gateway and sandbox descriptions are target architecture, not runnable code or evidence of isolation. Do not treat the documents as deployment instructions or a security certification.
