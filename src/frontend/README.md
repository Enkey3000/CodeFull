# Frontend source

The supplied source is a single-file interactive HTML prototype in `prototype/codefull-prototype.html`. It is preserved as provided and is included for design reference.

The PRD and Backend Plan propose a future React/TypeScript application using generated API clients. That production frontend has not been supplied or implemented here. The prototype contains static/sample values and simulated interactions; it must not be presented as a deployed product or connected to real code execution without a separately designed and reviewed service boundary.
